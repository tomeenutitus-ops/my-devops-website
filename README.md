# My DevOps Website

A beginner-friendly frontend project for learning a CI/CD pipeline.

## Files
- `index.html` — website structure
- `style.css` — website design
- `script.js` — small interactive feature

## Run locally
Open `index.html` in a web browser.

## Learning path
1. Create and test the website locally.
2. Upload the project to GitHub using Git.
3. Configure Jenkins to retrieve the repository.
4. Build a Docker image.
5. Deploy the container to an AWS EC2 instance.
